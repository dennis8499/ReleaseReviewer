## 已確認阻擋項

### R-001｜P1｜數量為零時平均金額計算會失敗

**阻擋原因**：正式統計流程允許零數量，本次移除防護會使該必要流程中斷。

**觸發條件**：以數量 0 計算平均金額。

**影響**：原本回傳零的流程改成除以零例外。

**處理方式**：開發恢復零數量的處理。

**證據**：entry/src/service.py:7-8；entry/src/service.py:1-4。
**情境**：已實際重現，執行紀錄見後文。

### R-002｜P1｜新增發票流程讀取未定義設定而失敗

**阻擋原因**：本次新增的正式發票準備流程必然讀取不存在的必要鍵，流程無法完成。

**觸發條件**：發票準備流程讀取檔案內的必要逾時設定。

**影響**：設定檔沒有該鍵，讀取時發生例外，發票準備流程中斷。

**處理方式**：開發補齊必要設定，或依產品需求提供可用的預設行為。

**證據**：entry/src/service.py:5-11；entry/src/settings.json:1-1；entry/src/application.py:10-12。
**情境**：已實際重現，執行紀錄見後文。
