# ReleaseReviewer 0.9.0

發布日期：2026-10-28。由正式版 0.8.0 升級。

## 本版更新

- Session 支援直接執行 worklist，依 Repo 批次讀取並以 blob 去重；選用共享內容回應時，仍逐筆保留固定 Repo、來源、版本、路徑及行號。成功 checkpoint 和失敗位置可續用。
- start 的完整驗證建立收據；step 重新核對實際使用快照的來源描述、檔案內容與目錄結構後才重用結構驗證。舊 context 繼續完整驗證，finish 仍獨立驗證全部快照、引用及搜尋紀錄。
- 根據最終入口版本與 supporting Repo 固定 HEAD 讀取適用 `AGENTS.md`。初始待讀只預載必要 merge-parent，其他固定歷史仍可追查。
- 新草稿的 `code_risks` 連回固定 Diff 與因果說明，刪除或改名可引用舊版位置和已驗證的最終路徑缺失。七類依賴、跨 Repo 查證、必要缺口及人工 Checklist 保留。
- `network_log` 明確記錄同步原因、階段、每個 remote 的 fetch 嘗試及成功數；本機分支與 supporting Repo 不連線，同次請求續跑不重新同步。

## 驗證與已知限制

- Windows／Python 3.14 的 27 個模組、253 項測試全部通過；包含 19 項既有 session、獨立套件、交錯 Repo 及 Windows 長路徑。完整紀錄與先前失敗／修正過程見[候選驗證紀錄](../candidate-optimization-validation.md)。
- 相同來源的合成 helper 案例各五組配對、20 個樣本均成功且證據一致。單 Repo 讀取／搜尋中位數由 12.59 降至 3.77 秒，Group 由 11.13 降至 3.64 秒；這不是 Agent 端到端量測。
- 使用者在已知限制下要求發布：三模型語意盲測與單 Repo／Group 各六組完整 Agent 配對尚未執行，不能宣稱審查品質或完整審查時間已達原訂目標。正式發布仍須通過獨立 CI 的 Windows／Linux、Python 3.10／3.14 完整矩陣。
- 工作區全域安裝的技能仍為 0.3.1，WorkflowKit 離線包仍為 0.8.0；本次 Release 不會自動升級這些既有安裝。工作台完整 unit suite 曾被其他程序清理共享編譯輸出而中斷；相關八項隔離測試及完整 TypeScript 檢查已通過。

發布內容維持 Context／Draft／Report v3 與單一繁體中文報告；實際部署、權限及環境狀態仍由人工核對。
