# ReleaseReviewer 0.10.0

發布日期：2026-10-30。由 0.9.0 升級。本版依使用者確認的進度發行，保留未完成的驗收項目；整體改善目標仍未宣告達成。GitHub tag workflow 先驗證 Windows／Python 3.10 與 3.14 完整測試，再核對 canonical ZIP 與 provenance 後發布正式 Release。

## 本版更新

- 批次解析固定 commit/tree、`AGENTS.md` 與引用 blob，按 Repo 及 blob 去重，保留來源、SHA、路徑、行號與搜尋紀錄的個別驗證。
- 記錄階段時間、Git／搜尋／blob 操作量，提供有 JSON pointer、字串 offset 與續頁位置的分頁證據；回應維持 24 KiB 上限。
- 支援 Windows 長路徑、hardlink 不可用時的 artifact fallback，以及可恢復的 session 清理。
- 明確限制 Git 網路同步：本機分支離線；明確遠端依 remote 精確 fetch；同 request 續跑使用固定證據。靜態 Repo/base/head 審查不呼叫 GitLab API。
- 縮短共用技能載入文字，按情境載入 Group、資源與異常恢復細節；維持單 Repo、Group、Context／Draft／Report v3 及 legacy 輸出。
- 擴充 DB/Table、FTP、SFTP、目標變更、權限與跨 Repo contract Checklist；網路核對項帶回具體依賴目標與連線／服務身分。

- Windows 11／Python 3.14.7 完整 regression suite：264 項通過，647.158 秒。
